## FIX 1-A — Protect localStorage read on initial render

REPLACE:

```js
vehicleType: localStorage.getItem('selectedVehicleType') || "",
```

WITH:

```js
vehicleType: (() => {
  try {
    return localStorage.getItem('selectedVehicleType') || "";
  } catch (_) {
    return "";
  }
})(),
```

PURPOSE:
If Safari blocks localStorage access inside the iframe, the form must continue rendering instead of crashing.

---

REPLACE:

sessionStorage.setItem(

WITH:

try {

## FIX 2 — Replace iframe alert() with inline validation error

REPLACE:

```js
alert("There was an error processing your request. Please try again.");
```

WITH:

```js
setValidationErrors([
  {
    field: 'submit',
    message:
      'There was an error processing your request. Please try again.'
  }
]);
```

PURPOSE:
Safari suppresses alert() inside cross-origin iframe contexts.
Use the already-existing inline validation UI instead.
